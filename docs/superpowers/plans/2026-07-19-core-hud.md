# Core HUD (Gap G4) Implementation Plan

> **For agentic workers:** execute with superpowers:executing-plans. Scope from
> the master plan's G4 brief; decided semantics from MECHANICS_REFERENCE §2
> (pip display: filled/partial/empty + visually locked reserved pips).
> Functional/debug-grade visuals — the art pass is Milestone D.

**Goal:** One player HUD scene usable in both the test arena and
match_session: Resonance pips (partial fill + locked reserved), health, ammo
(mag + reserve + reloading), active-weapon indicator, combat-gating indicator,
denial feedback for insufficient-Resonance casts, scoreboard overlay
(`scoreboard` action), and a kill feed.

**Architecture:** `scenes/ui/player_hud.tscn` + `scripts/ui/player_hud.gd` —
a CanvasLayer bound to a local `FPSController` via `bind(player)`; all values
read in `_process` (view-only). The existing debug `resonance_hud.gd` is
replaced by it. Kill feed and scoreboard listen to `died` signals and
`MatchState` (absent in the arena → those panels self-hide). Denial feedback
hooks a new `cast_denied` signal on `FPSController` (emitted on fresh ticks
when a Repulse press fails the Resonance check).
