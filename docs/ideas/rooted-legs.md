# Rooted Legs

**Type:** Cybernetic (Augment) — **Leg slot** (mutually exclusive with Hopper Legs, Cheetah Legs)
**Status:** Idea (owner-approved direction) — recorded 2026-07-17

## Concept (owner spec)

- While planted (stationary), immune to Repulse knockback, Tangle pull, and displacement effects generally — the anti-movement-tech legs.
- **Consideration: ability to stick to walls and ceilings** — planting isn't just for floors.

## Interactions with decided systems

- **Completes the Leg trilemma:** jump far (Hopper) / run fast (Cheetah) / stand immovable (Rooted).
- **Counter-web addition:** the first hard counter to the force-movement family (Repulse shoves, Tangle vortex). Turns "Repulse them off the ledge" into a read: is that anchor chromed?
- **Wall/ceiling planting is a big multiplier:** a Rooted sniper planted on a ceiling is a genuinely new sightline class — combos absurdly well with the Sniper loadout (get up via Repulse+Glide, plant, unshovable). May want planting to be poseable only while stationary for N seconds, with an audible anchor sound (counterplay: you can hear a rooted player).
- **Power Arm overlap to resolve:** Power Arm "negates the stagger from Repulse" (arm-based, works while mobile); Rooted Legs grant full displacement immunity while planted. Distinct if stagger (aim flinch) and displacement (velocity) are separate effects — define both when promoting either.
- **Rounding the decided systems:** planted state is rollback state; displacement immunity is a check in the victim's own tick (same pattern as Tangle pull) — cheap.

## Open questions

- Plant activation: automatic when stationary (threshold ~0.5 s), or an active toggle?
- While planted: can you turn/aim freely (presumably yes), crouch, fire heavy weapons with no movement penalty?
- Ceiling/wall plant: how do you get there (needs Repulse/Glide/Hopper... which are slot-excluded — so via Repulse+Glide only) and how do you detach (jump input)?
- Does immunity extend to the SELF-push of your own Repulse (probably yes while planted — no rocket-jumping out of plant)?
