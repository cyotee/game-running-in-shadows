# Idea Tracker

Future-consideration designs, one file per idea. Not commitments — record, research, then promote to MECHANICS_REFERENCE via the usual decision process when ready.

**Workflow:** capture the owner's spec verbatim-in-spirit → note interactions with decided systems → accumulate research/playtest thoughts → when promoted, move the decided design into MECHANICS_REFERENCE §4.A and log it in §11; keep the idea file with a "PROMOTED" status line.

## Cross-cutting implications introduced by this batch (2026-07-16)

- **New cybernetic slots:** **Skin** (Optical Camouflage, Armor Skin) and **Leg** (Hopper Legs, Cheetah Legs) join Eye and Full Body. Same rules assumed: shared slot = mutually exclusive, permanent once purchased.
- **New damage type:** **spirit** (aka "soul" — one type, owner-confirmed 2026-07-16). Bypasses physical damage reduction. Used by Resonance Bolt and Death Field; Death Field's Troll-resistance is an **ability-specific carve-out**, not a property of the type. Extends the direct/pellet/windup/explosive/melee taxonomy.
- **Corpse economy grows:** Devour (destroy corpse → heal) and Corpse Bomb (trapped corpse) both deepen the decided corpse defense/destruction/looting pillar.
- **Aim-vector manipulation as a mechanic family:** Smart Rig pulls view TOWARD targets; Optical Camouflage pushes view AWAY. These should share one implementation (signed view-force system).

## Trilemma design benchmark (adopted 2026-07-17, owner decision — soft guidepost, not a hard requirement)

Each slot / ability category aims for a **well-defined trilemma**: three competing identity choices. Once a category presents a real three-way decision, its design space is considered saturated *for now*. Current map:

**Already-complete trilemmas (existing decisions + tracked ideas):**
- **Full Body slot:** Smart Rig (aim automation) / Overclock (tempo, burning the body) / Corpse Bomb (death-trap) ✓
- **Eye slot** (if Deployable Camera lands here): Pulse Sight (on-demand wall pulses) / Smart Rig (forced tracking) / Deployable Camera (persistent remote viewpoint) ✓
- **Field Manifestations:** Lifebloom (heal) / Tangle (control) / Death Field (damage) ✓
- **Movement Manifestations:** Repulse (force) / Slip (teleport) / Wraith (phase) ✓

**Completed via owner approval 2026-07-17:**
- **Skin slot ✓:** Optical Camouflage (avoid damage) / Armor Skin (reduce damage) / [Capacitor Skin](capacitor-skin.md) (eat damage for power — may overcharge past locked pips).
- **Leg slot ✓:** Hopper Legs (vertical) / Cheetah Legs (horizontal) / [Rooted Legs](rooted-legs.md) (immovable while planted; wall/ceiling planting under consideration).
- **Summon Manifestations ✓:** Familiar (creature) / Clone (illusion) / [Puppet](puppet.md) (corpse — must outclass Familiar to justify the corpse cost).
- **Corpse Manifestations ✓:** Reclaim (revive) / Devour (consume) / Puppet (weaponize).

**Still one short (open design space per the benchmark):**
- **Organ slot:** Second Heart (sustain) / [Null Core](null-core.md) (resist — "poor man's Be a Dwarf") / **???** — Adrenal Surge REJECTED 2026-07-17 (overlapped Overclock with little to distinguish it). Third candidate must be neither tempo (Overclock's turf) nor sustain nor resistance.
- **Arm slot:** Spider Rope (grapple) / [Power Arm](power-arm.md) (strength + handling — Stabilizer Arm merged into it 2026-07-17) / **???** — third candidate wanted.
